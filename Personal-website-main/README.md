# Nisar Ahmed Hidayeti — Personal Website

My personal website and portfolio: who I am, what I've built, and how to reach me.

**Live:** [nisarahmedhidayeti.netlify.app](https://nisarahmedhidayeti.netlify.app/)

## Sections

* **Home** — animated intro, CV download and social links
* **About** — bio, skills, languages, achievements, journey and 2027 goals
* **Portfolio** — Phoenix Assistant, Smart Home Automation, websites and YouTube
* **Services** — web development, embedded/IoT, Python & AI tools
* **Contact** — working contact form (Netlify Forms) and links

## Built with

Plain HTML, CSS and JavaScript — no frameworks. Fonts: Inter & Space Grotesk. Icons: Font Awesome.

## Project structure

```
index.html
css/      heather.css (nav) · general.css (theme) · firstpage.css (hero)
          wholepages.css (sections) · animation.css (loading animation)
script/   animation.js (loading animation) · heater.js (nav)
          secondpage.js (reveal, videos, form) · general.js
images/
```

## Customising

* **Add YouTube videos:** edit the `VIDEOS` list at the top of the videos block in `script/secondpage.js`.
* **Contact form:** works automatically on Netlify (form name: `contact`); messages appear in the Netlify dashboard under *Forms*.
* **Colours:** change the variables at the top of `css/general.css`.
